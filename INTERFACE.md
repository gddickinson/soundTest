# INTERFACE.md — navigation map

Static site (no build, no server code). `index.html` loads `static/main.js`; pages are ES modules registered with the
hash router in `static/core.js` and loaded on first visit. The audio engine is one shared instance that survives page
changes.

## Entry and shared kit
| File | Contents |
|---|---|
| `index.html` | Shell: header nav, `#app`, footer, `#dock` (player bar), `#bg` canvas |
| `static/core.js` | Shared web kit (unchanged copy): `$`, `esc`, `list`, `route`, `lazy`, `go`, `onLeave`, `animate`, `start` |
| `static/style.css` | Shared dark neon theme (unchanged copy) |
| `static/style_app.css` | soundTest accent colours and all page styles (mixer, strips, dock, visualiser) |
| `static/main.js` | Registers pages, mounts the dock, keyboard shortcuts and background; remembers the last mix |

## Pure logic (no DOM / WebAudio; node-tested)
| File | Key exports |
|---|---|
| `static/catalog_data.js` | `SOUNDS` — GENERATED by `scripts/make_catalog.mjs` from the WAV headers |
| `static/catalog.js` | `CATEGORIES`, `CAT`, `sound(id)`, `search(q, cat)`, `defaultMode`, `totals`, `fmtDur`, `fmtSize` |
| `static/mix_codec.js` | `normalise`, `encodeMix`, `decodeMix` (share-link format), `audible` (mute/solo), `MAX_TRACKS` |
| `static/sleep_fade.js` | `sleepGain`, `sleepCurve`, `fadeStart`, `fmtClock`, `TIMER_CHOICES` |
| `static/loop_xfade.js` | `makeSeamless(channels, sr, fadeSec)`, `fadeSamples` |
| `static/scatter.js` | `planHits(next, until, every, chance, rand)`, `hitsPerMinute` |
| `static/presets.js` | `PRESETS`, `preset(key)` |

## Audio and browser services
| File | Contents |
|---|---|
| `static/audio_engine.js` | `engine` (EventTarget: `change`, `state`, `timer`, `preview`): graph, layers, `play/pause/toggle`, `add/remove/set/applyMix/clear`, `previewSound`, `startTimer/cancelTimer`, `level` |
| `static/loader.js` | `loadBuffer(ctx, url, sizeHint)` streaming fetch + decode cache, `loadState`, `pendingTotals`, `loader` progress events |
| `static/store.js` | localStorage (try/catch): `savedMixes`, `saveMix`, `deleteMix`, `lastMix`, `rememberMix`, `prefs`, `setPref` |
| `static/share.js` | `mixHash`, `shareUrl`, `syncHash` (replaceState), `copyText` |
| `static/visualiser.js` | `makeVisualiser(canvas, getAnalyser).draw(mode, t, live)`, `MODES` (spectrum, scope, orbit) |
| `static/keys.js` | `installKeys`, `SHORTCUTS` (fires `layer-select`, `vis-next`, `timer-toggle` window events) |
| `static/dock.js` | `mountDock` — the player bar |
| `static/bg.js` | `startBackground` — subtle level-reactive background (off with reduced motion) |

## Pages (route → file)
| Route | File | Uses |
|---|---|---|
| `#/` | `static/home.js` | catalog totals, presets, visualiser |
| `#/mixer` (`?mix=`, `?cat=`, `?q=`) | `static/mixer.js` | `library_panel.js`, `strips.js`, `timer_panel.js`, `mixes_panel.js` (also exports `load(mix)`) |
| `#/visualiser` | `static/visual_page.js` | visualiser, full screen |
| `#/presets` | `static/presets_page.js` | presets + saved mixes |
| `#/credits` | `static/credits.js` | fetches `THIRD_PARTY.md` and the Korg `Readme.txt`; file table |
| `#/about` | `static/about.js` | how it works, shortcuts, run/test instructions |

## Other
| Path | Contents |
|---|---|
| `classic/` | The original page (`index.html`, `script.js`, `style.css`), audio paths `../audio/` |
